# Over-the-air updates

Xaman can receive JS-only updates over the air (self-hosted, signed expo-updates; every store build is its own
runtime).

The documentation lives in the backend repository, which is private:
**[XRPL-Labs/Xaman-API](https://github.com/XRPL-Labs/Xaman-API), [`docs/ota-updates.md`](https://github.com/XRPL-Labs/Xaman-API/blob/master/docs/ota-updates.md)**.
It covers how updates work, what may ship over the air, publishing, store builds and troubleshooting.
